# Backend - Finance Dashboard API

## 📌 Overview
This backend provides a simple API for the Finance Dashboard application.
It returns financial data such as income, expenses, and savings.

---

## 🚀 Features
- REST API to fetch financial data
- Simple JSON response
- Easy frontend integration
- Uses mock/static data

---

## 🛠️ Technologies Used
- Node.js
- Express.js

---

## ▶️ How to Run

1. Go to backend folder:
cd backend

2. Install dependencies:
npm install

3. Run server:
node server.js

---

## 🌐 API Endpoint

GET /api/data

Response:
{
  "income": 50000,
  "expense": 20000,
  "savings": 30000
}

---

## ⚠️ Note
This backend is for demo purpose only.
Frontend can work independently.
