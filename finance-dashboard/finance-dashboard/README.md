# Finance Dashboard

## 📌 Objective
To build a clean and interactive finance dashboard UI using React and Node.js.

## 🚀 Features
- Display Income, Expense, and Savings
- Dynamic calculation using user input
- API integration using Node.js backend
- Data visualization using Pie Chart

## 🛠️ Tech Stack
- Frontend: ReactJS
- Backend: Node.js, Express
- Chart Library: Chart.js

## ▶️ How to Run

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start

## 📊 Output
- Shows financial data
- Updates dynamically
- Displays pie chart visualization
